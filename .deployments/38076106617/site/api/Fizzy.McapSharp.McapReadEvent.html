Parameters

Kind McapReadEventKind

Read requests input, Seek requests repositioning, ReadChunk requests indexed compressed chunk data; Record and Message deliver bytes.

Opcode byte

Record opcode for Record events; not a general event discriminator.

Length ulong

Requested byte count for Read/ReadChunk, delivered body or payload bytes for Record/Message. BufferTooSmall reports required destination capacity.

Offset ulong

Compressed-data byte offset from the MCAP origin for ReadChunk. For Seek with Begin this is a byte offset from the MCAP origin; Current/End encode a signed displacement, recovered with unchecked((long)Offset).

Origin SeekOrigin

Seek origin, meaningful only for Seek events.

Header McapMessageHeader

Message header, meaningful only for Message events.
