本地补丁边界

English | 简体中文

维护者应优先使用未修改的上游 API。只有明确的绑定层所有权或性能契约无法通过上游 API 或合理的纯绑定层适配实现时，才允许补丁。保留格式状态机及语义，不修改 codec 分配器、不增加总内存记账、不优化上游内部实现。补丁仅在本地维护，不向上游提交。

当适配需要不成比例的重复状态或生命周期机制时，应将其与必要的最小访问能力或存储所有权扩展进行比较。记录目标契约、被否决的适配方案及其具体复杂度，并比较两者的正确性、维护和上游升级成本。在上述边界内选择更简单且可维护的方案；复杂度不能作为增加便利 API 或修改无关上游实现的理由。独立的行为、生命周期和性能证据要求仍然适用。

允许的扩展

范围 上游限制与不采用的替代方案 本地契约
storage.rs、linear_reader.rs、indexed_reader.rs 及 lib.rs 导出 借用事件在推进后失效。逐消息复制 lease／重试体会增加绑定层 payload 复制；只延长解析器寿命不能阻止缓冲复用。 共享不可变范围在推进、解析器释放及缓存淘汰后保留所有者。已发布范围不覆盖；重叠写入前更换仍被引用的存储。indexed 输入接收已有缓冲或映射的所有权，拒绝与声明解压长度不符的未压缩共享输入；直接填充仅暴露未发布可写区域。
storage.rs 的 shares_backing 共享切片提供容量但不提供 backing 身份。同一分配内 payload 地址可不同，相同容量也不能证明共享所有权。纯绑定层分组只能猜测身份或连密集选中数据也复制。 只读 Arc 身份比较，用于发布前对连续 owned 排序范围分组；地址不跨 C ABI。紧凑化由绑定层决策，不改变上游状态机和分配策略。
write.rs 的 contains_channel 批次须在写入前检查未知 channel。绑定层另建注册表会重复维护上游声明状态，包括自动声明。 只读成员查询，记录校验和写入仍由上游执行。
write.rs 的 into_inner 后 Drop 上游 Drop 即使已取走输出仍调用 finish，与显式 Complete 和释放不完成的契约冲突。替换为虚拟输出仍执行不必要的格式完成。 输出已取走时跳过 Drop 完成；仍持有输出的普通上游 Drop 行为不变。绑定层在不 Complete 的释放中取走输出。

补丁不改变 CRC 规则、记录解释、压缩算法、索引排序或 writer 默认值。绑定层可选的完整 chunk 缓存会校验整个目标 chunk，可能比上游前缀 seek 更早报告尾部损坏；这属于绑定层行为。

证据与维护

UPSTREAM.json 保留官方 crate 文件哈希，PATCHES.json 仅列本地差异；scripts/check_vendor.py 拒绝未声明差异。API 清单分别标记官方声明与本地扩展。

python scripts/test_upstream.py 独立编译仅引用 registry 的参考实现，对照补丁版本在 None／Lz4／Zstd 下的确定性写入字节、记录、消息、索引定位、有界样本的所有截断点及抽样损坏输入。有限测试不证明全部格式行为。原生共享存储测试检查指针一致性、保留生命周期及 pending 交付零分配；托管测试覆盖释放、映射、重试和异步所有权。Release 分配门禁独立检查预热后的托管热路径。

sort_arena 测试覆盖 backing 身份、紧凑阈值、选中 payload 仅复制一次、分段边界及释放后结果寿命。memory_probe::sort_compaction_profile 对相同输入比较共享与紧凑策略，检查旧 backing 分配释放并报告保留容量、复制字节和组内新旧存储重叠。SortStorageTests 覆盖不同压缩和输入模式下的过滤回退排序、同时间戳、逆序、重试和 lease 寿命。这些测试证明绑定层存储行为；格式参考仍使用独立上游比较。

修改补丁时重新审查必要性及纯绑定层替代方案，同步本文与相应清单（不得改写上游哈希来接受补丁），并运行独立行为、生命周期及分配检查。便利 API 或上游资源策略不构成扩大补丁的理由。
