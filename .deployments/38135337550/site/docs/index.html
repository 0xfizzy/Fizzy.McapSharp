简体中文 · GitHub repository

Fizzy.McapSharp reads and writes MCAP files from .NET 8. Applications define payload encoding and clock origins. Choose the entry for your task; no Rust or native ABI knowledge is needed to begin.

Getting started

Read the README for purpose and supported platforms. When ready to code, follow your first recording to install from NuGet, write, read, filter and optionally validate a file.
