# 原生分配清单

[English](memory-accounting.md) | 简体中文

本清单供维护者审计原生内存硬上限。预留不等于实际存活分配证据。下表中的待完成项是未完成的计费工作，不是允许排除在预算之外的资源。

| codec C 工作区 | 编码／解码 | custom alloc/calloc / custom free | 头部与工作区一起预留；编码线程 0/1/2、解码分配失败注入；独立分配身份探针对账待完成 |

## Codec 失败契约

固定的 zstd-sys 源码保留配置的工作线程数。受审查补丁在清零前检查自定义分配返回的空指针，在部分池初始化期间保留自定义分配器身份，并在清理时避免遍历不存在的任务表。补丁指纹覆盖这些 C 源码，以及构建脚本对源码目录的依赖。生产 crate 和独立 MCAP 测试使用同一补丁 codec 版本。

codec 内部分配失败是终止错误。回调不等待消费者、不调用托管代码。测试逐次拒绝观测到的分配申请，并验证上下文销毁后域占用归零。系统分配失败与域预算拒绝属于不同错误；最终结构化 ABI 表示仍待完成。

## 验收边界

当前清单不能证明完整堆硬上限。必须完成全部待完成计费项、域级等待票据及完整所有权统计，才能移除该限制。操作系统线程栈／运行时资源、分配器碎片、托管／调用方缓冲和映射驻留页与受控堆预算分别说明。
