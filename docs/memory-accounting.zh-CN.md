# 原生分配清单

[English](memory-accounting.md) | 简体中文

预留的所有权容量随扩缩容及弱域计费转移保持一致；扩容失败不改变所有权账本，最终释放在同一次账本更新中清除剩余容量。缓存载荷淘汰后，reader 仍持有目录控制壳；升级得到的回收句柄持有操作 pin。

Parser 必须在输入分配或状态推进前选择预算域，之后不能替换；重复选择同一域仍然有效。部分摘要的回退扫描在请求输入前继承 reader 的资源域及记录长度上限；拒绝时恢复源位置并释放扫描 parser。索引 reader 在构造时确定域，摘要重置保留原域，chunk codec 在初始化前接收指定域。

共享载荷引用标明 parser、pending、当前操作、cache 或 lease 所有权。缓存访问在缓存锁内取得操作 pin，覆盖描述符页；淘汰移除缓存所有权，不影响已有 pin。计数可判定已接入存储的回收资格，但控制块、剩余嵌套存储及等待票据仍需接入，才能完成整个域的收口。

仅用于测试的 `allocation-audit` feature 将显式分配身份交给独立、固定容量的系统分配器探针。探针对应指针与分配序号，核验分类存活容量及累计分配次数／字节，并独立观察释放。解释未归属分配数量时应隔离执行身份测试；并行测试会引入无关分配事件。即使所有已登记身份都吻合，未归属分配仍是待完成项。该 feature 仅由 native 的开发依赖启用，不承担生产计费。


共享分段索引的根、目录和数据页保持 Parser 或 Operation pin；新节点发布前取得同类 pin，旧节点在增长及失败回滚期间持续被固定。共享克隆按唯一存储登记容量，writer 与 reader 使用各自的持有者类别。嵌套值必须独立实现计费与持有者登记；目录计费不代表其内容已完成计费。

控制块分配和分页追加／插入提供固定结果路径，保留结构化预留失败而不装箱 I/O 错误。借用字符串映射校验、保留声明与索引、声明发布及摘要索引发布使用这些路径。独立探针同时覆盖真实容量限制（包括少 1 字节的边界）和注入的分配器失败，对账物理分配，并核验容量与所有权回滚。尚未迁移的调用点仍使用兼容 I/O 适配器，仍需完成闭环。

共享摘要控制块、缓存控制块和回收注册页采用固定结果的分配事务。缓存索引／条目发布及 writer 规范键同样直接传播固定错误，不经过兼容 I/O 桥接。独立探针覆盖真实容量拒绝及注入分配失败，包括弱引用控制块保持和注册页回滚。随机 chunk 初始化借用压缩名称，与 owned 解析共用载荷边界检查；成功的头部解析及截断错误编码不申请原生堆内存。不支持的压缩名称诊断及其余 I/O 适配器仍是未完成的计费路径。

随机 metadata 与 attachment 读取把调用方索引解析为精确计费的共享记录，再用官方 parser 对共享输入范围进行校验，不物化 owned 记录或复制载荷。差分测试覆盖截断、变异、CRC 及多余记录；独立分配探针包含 8 MiB attachment 和逐次分配拒绝。调用方缓冲交付仅统计成功复制，容量探测重试不计入。

Snapshot 配置先执行无堆分配的预算 ID 扫描，再建立计费 JSON 文档。扫描支持转义键、重复键后值覆盖、有界递归和固定错误。复制、mapped 及 reader 来源的 snapshot 入口均使用此路径；全文件验证在默认域解析控制文档。真实容量拒绝和独立分配身份测试验证了先选择域、后分配文档的顺序。数值 JSON 错误构造仍待完成。索引预扫描采用计费分页表存储 chunk 偏移与长度，通过二分查询及已使用标记拒绝重复索引，替代未计费树。

Writer 创建先选择域，再解析计费配置文档。保留的 profile／library 文本具有精确字节与共享控制块计费，并登记 Operation 所有权；原生 options 克隆共享该存储。域不匹配会在写入文件头前被拒绝。独立探针对账构造文档、文本、控制块及逐次分配失败；真实容量测试覆盖文本拒绝与写入前构造失败。初始化峰值包含临时 JSON 页，因此仅按创建后常驻容量设置的预算可能拒绝创建。原始 Rust 不可失败字符串 setter 继续作为兼容接口；绑定使用可失败的计费 setter。Reader 和 engine 配置也采用计费文档。

Indexed reader 选中的 Channel ID 使用按需分配的 256 项 u16 页面，并登记 Parser 所有权；已移除原先按通道倍数估算的预留及未计费 ID 树。跨页选择、逐次页分配失败和独立分配身份测试验证实际存活容量，无未使用估算。原始 Rust 调用方 options 的 topic 名称集合仍由调用方拥有。

Indexed reader 创建可同步求值借用的 topic 判断函数，仅保留计费 Channel ID 页。原生顺序 reader 准备索引访问时复用已有过滤条件，不再克隆 topic 名称树。保留的 topic 字符串和构造 JSON 使用计费存储。

索引 chunk／message／slot 页追加及原生缓存容量预留直接传播固定分配错误。真实容量测试覆盖临时不足和永久拒绝，直至 ABI 编码均不分配错误堆内存。尚未转换为固定结果的存储和 parser 兼容 I/O 适配器仍待完成。

## Codec 失败契约

固定的 zstd-sys 源码保留配置的工作线程数。受审查补丁在清零前检查自定义分配返回的空指针，在部分池初始化期间保留自定义分配器身份，并在清理时避免遍历不存在的任务表。补丁指纹覆盖这些 C 源码，以及构建脚本对源码目录的依赖。生产 crate 和独立 MCAP 测试使用同一补丁 codec 版本。

codec 内部分配失败是终止错误。回调不等待消费者、不调用托管代码。测试逐次拒绝观测到的分配申请，并验证上下文销毁后 codec 工作区占用归零；存活域仍保留根控制存储。系统分配失败与域预算拒绝属于不同错误；固定 codec 失败的 ABI 明细包含资源、容量、阶段、失败分类及终止标记。

线性和摘要 reader 可在构造时接收资源域，不再先分配并丢弃默认域；使用现有域构造不产生堆分配。摘要内部 parser 控制对象采用精确计费的 Box。共享摘要 Schema／Channel 的文本、schema 字节、共享控制块和分页 metadata 均精确计费。writer Complete 和 SummaryReader 直接构造、解析及序列化此表示；共享克隆在 writer 释放后保持有效。覆盖截断／损坏输入差分、逐次分配拒绝和跨页 metadata 生命周期。顺序／buffer reader 及 lease 引擎均保留此精确共享声明，查询页面带 Parser pin，已移除旧声明估算。顺序 wire schema ID 独立于解析后的 schema 引用，保持 records-only 扫描以及与预载摘要比较的语义。记录消费后的声明分配拒绝为终止失败。普通 Rust owned helper 输出和 JSON 输出临时存储仍未完成。使用预先创建的域及显式线程数的 None／Lz4／Zstd 完整 writer 样本已逐项对账所有分配，但这不代表错误对象构造、冷路径导出及所有 reader 路径已收口。

容量票据使用精确计费的稳定节点，在可能等待的操作开始前分配。域账本只保存侵入式链表链接；票据释放时先持账本锁注销，再释放存储。登记与容量检查使用同一把锁；足量释放会保留可重试状态，即使容量随后立即被其他操作占用也不会丢失事件。空闲池与仅缓存持有的存储计入可回收容量。登记、查询与取消不分配内存，包括登记拒绝和等待失效的错误构造。票据创建及准入以固定 StorageFailure 值传播至 ABI 编码；预算耗尽与注入分配失败均不再申请错误堆存储。异步 lease 引擎预分配票据，失败回滚后登记需求；重试容量包括精确描述符页面和控制块。managed 等待先订阅、再检查票据状态，取消时注销。容量变化将对应域的通知入队，不比较当前占用。等待准入比较完整重试需求与外部可释放的唯一容量；无关的小 lease 不能作为等待依据。有限的 lease／缓存销毁、计费控制块／树／切片销毁、操作 pin 释放与空闲块回收保护移除所有权到实际归还存储之间的窗口。析构异常展开也会结束释放保护；存活的弱引用控制块继续计费，不能成为无限等待的依据；这些释放过程结束后，严格票据会拒绝外部容量不足的等待。计费预算句柄内含域注册链接、listener 状态和合并通知队列链接。账本内仅执行原生通知入队，只有发生变化的域进入队列；有界分发在账本和注册锁之外调用回调。释放先清除 observer，再注销和销毁句柄。请求级操作所有权仍未完成，尚不能视为完整等待协议。

## 验收边界

当前清单不能证明完整堆硬上限。必须完成全部待完成计费项、域级等待票据及完整所有权统计，才能移除该限制。操作系统线程栈／运行时资源、分配器碎片、托管／调用方缓冲和映射驻留页与受控堆预算分别说明。

线性 parser 的输入扩容、共享输入搬移和解压存储预留直接传递固定存储错误；只有分配成功后才更新可写边界。测试覆盖真实容量拒绝、溢出、已有输入及可写范围保留、释放容量后重试，以及经 ABI 错误编码的独立分配身份对账。其余 codec／I/O 兼容适配器和冷路径诊断仍需审计。

Reader 创建先选择预算域，再解析配置；保留的 topic 字符串按实际字节容量计费并登记 Parser 所有权，topic 查询使用排序分页描述符。Engine 创建同样使用计费配置；indexed engine 的 Memory 缺省或为 null 时继承 summary 域，包含重复键及转义键情况。Indexed engine 同步求值借用过滤条件，只保留选中的 Channel ID，不保留 topic 名称树。初始化预算须覆盖临时配置页及常驻状态。Buffer reader 控制入口和数值 JSON 错误构造仍需审计。
