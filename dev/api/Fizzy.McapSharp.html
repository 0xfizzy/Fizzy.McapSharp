Classes

McapAsyncMessageReader

Incremental asynchronous resolved message reader. Owns its Stream unless leaveOpen is true. Allows one outstanding operation, which must be consumed exactly once. Expanded reads validate record bodies and declaration references independently of CRC options.

McapAsyncRecordReader

Incremental asynchronous record reader. Owns its Stream unless leaveOpen is true. Allows one outstanding operation, which must be consumed exactly once. Expanded reads validate record bodies and declaration references independently of CRC options.

McapAttachment

Owned attachment payload and fields. Times use caller-defined nanoseconds.

McapAttachmentHeader

Attachment fields. LogTime and CreateTime use caller-defined nanoseconds.

McapAttachmentIndex

Owned attachment index with byte Offset from the MCAP origin (the initial Stream position for Stream inputs) and record Length; DataSize counts payload bytes and times are nanoseconds.

McapAttachmentRecord

Owned attachment body and stored CRC.

McapBatchWriteException

A failed batch may have written a prefix and part of its failing record.

McapChannel

Resolved channel declaration with optional schema and metadata. Reader results own their data; direct construction retains supplied references.

McapChannelDescription

Immutable resolved channel declaration shareable across messages and threads; survives reader disposal.

McapChannelRecord

Owned channel record retaining the schema ID rather than resolving the schema object.

McapChunkFlattener

Expanded file records with record-body and declaration-reference validation independent of CRC options.

McapChunkHeader

Chunk descriptor. Times are nanoseconds; sizes are bytes; UncompressedCrc covers expanded record bytes.

McapChunkIndex

Owned chunk index. ChunkStartOffset and MessageIndexOffsets are byte offsets from the MCAP origin (the initial Stream position for Stream inputs); lengths and sizes are bytes; times are nanoseconds.

McapChunkReader

Records from one encoded Chunk body, without its outer record header. Validation is local to the chunk; declarations may live elsewhere.

McapChunkRecord

Owned chunk record. Data contains the compressed bytes described by Header.

McapException

A structured MCAP failure. Reader sessions normally become terminal; writer continuation is limited to CanContinueWriting.

McapFormat

Constants identifying the MCAP wire format and bundled upstream implementation.

McapHeader

Owned file header containing the profile and writer library identifier.

McapIndexedQuery

Indexed message selection. Omitted and empty queries use ascending log time. Requires complete indexes and never falls back to scanning or buffered sorting.

McapIndexedReader

Owns copied or explicitly mapped input and its official summary, independently of the originating session. Indexed-reader message callbacks must not invoke operations on any indexed reader or prepared chunk index, including disposal.

McapIndexedReaderOptions

Limits only the indexed reader cache, not upstream allocations or live leases.

McapLinearReader

Top-level records; chunk bodies remain encoded. Does not validate declarations hidden inside chunks.

McapMessage

Message with resolved declarations and payload bytes. Reader results own independent data; direct construction retains supplied references. Times use caller-defined nanoseconds.

McapMessageBatchLease

Owns stable native message storage. Keep this lease alive until all payload access has finished. Access and disposal must not overlap. Payload spans expire on disposal. A payload slice can retain an entire chunk, copied input or mapping; payload length is not retained capacity.

McapMessageFilter

Selects messages during a sequential file-order scan. Omitted and empty filters are equivalent; filtering never selects indexes or requests sorting.

McapMessageIndex

Owned per-channel message index, including channels with an empty Records collection.

McapMessageLease

An independently retained message. Do not dispose concurrently with payload access.

McapMessageReader

Resolved messages with declaration-reference validation. Results follow the selected caller-buffer, borrowing or retained-storage ownership contract.

McapMessageRecord

Owned message record with an independent payload array.

McapMetadata

Owned named string metadata record.

McapMetadataIndex

Owned metadata index with byte Offset from the MCAP origin (the initial Stream position for Stream inputs) and complete record Length in bytes.

McapPreparedAttachment

Copies attachment fields. The payload is supplied separately at each write. Preparation does not write or register anything.

McapPreparedAttachmentStart

Copies segmented attachment fields and the exact declared byte length. Preparation does not write or register anything.

McapPreparedChannel

An immutable native snapshot. Preparing does not register or write declarations.

McapPreparedChannelRegistration

Copies a channel registration descriptor referring to a schema ID. This is distinct from a resolved prepared channel. Preparation does not write or register anything.

McapPreparedChunkIndex

An immutable, native-owned copy of a Chunk index for repeated operations across indexed readers.

McapPreparedMetadata

Copies named metadata for repeated synchronous writes. Preparation does not write or register anything.

McapPreparedSchema

Copies schema fields and bytes for repeated registration. Null ID requests allocation; explicit ID must be nonzero. Preparation does not write or register anything.

McapQuery

Message selection with inclusive StartTime and exclusive EndTime. Topic and Topics are mutually exclusive. Explicit query execution defaults to ascending log time for both omitted and empty queries. Use McapMessageFilter for sequential file-order selection.

McapRawMessageReader

Raw message headers and payloads. Encountered declarations are collected, but a message need not reference a known channel. No implicit resolved-message enumeration is provided. Results follow the selected caller-buffer, borrowing or retained-storage ownership contract.

McapRawRecord

An independently owned opcode and unparsed record body. Data excludes the opcode and length prefix. Use McapRecords.Parse for typed fields.

McapReaderFactory

Reusable reader factory with instance methods for a file path and static methods for Streams; construction validates the path but does not open the file. This factory owns no disposable resources. Each opened session or enumeration owns an independent native reader and its input.

McapReaderOptions

Parsing and integrity options for one read session. Defaults do not prove full-file integrity; a strict complete expanded synchronous scan provides full-file validation. High-level body and declaration checks do not depend on this preset.

McapRecordAccessor

Serialized random access over one seekable file or Stream, without copying the complete input. Offsets are relative to the initial MCAP position. Parsing or I/O failure terminates this reader; independent copied indexed readers survive disposal.

McapRecords

Parses record bodies into independent owned models and exposes MCAP layout helpers.

McapRecoveryResult

Result of explicit prefix salvage. IsFullyValidated is true only after a strict complete scan; Error describes the failure that ended salvage, if any.

McapSansIoIndexedReader

Caller-driven indexed parser. Performs no I/O. Supply requested input before advancing again; buffer-size negotiation preserves pending delivery and other protocol failures are terminal.

McapSansIoLinearReader

Caller-driven linear parser. Performs no I/O. Supply requested input before advancing again; buffer-size negotiation preserves pending delivery and other protocol failures are terminal.

McapSansIoSummaryReader

Caller-driven summary parser. Performs no I/O. Supply requested input or acknowledge the requested seek before advancing again; protocol failures are terminal.

McapSchema

Schema declaration. Reader results own independent mutable schema bytes; direct construction retains the supplied array.

McapSchemaDescription

An immutable declaration snapshot that can be shared across messages and threads.

McapStatistics

Owned summary statistics. Message times are nanoseconds; counts describe the recorded data section.

McapSummary

Summary model. Library-returned snapshots own independent collections; direct construction retains supplied references. Contains complete schema/channel declarations, with shared schema references inside one result. Separate results are independent. Arrays and collections retain ordinary .NET equality semantics. Size grows with file indexes and declarations.

McapSummaryReaderOptions

Options for direct Sans-I/O summary reading. FileSize permits end-relative seeks to be resolved against the caller-provided source length.

McapSummaryRecordReader

Retained summary records. The reader survives disposal of its originating writer, snapshot or summary parser; it does not scan file contents.

McapWriter

A serialized MCAP writer. Complete explicitly to finish the format; disposal only releases resources. Native or I/O failures are terminal except for configured audited pre-mutation rejections.

McapWriterOptions

Writer configuration fixed at construction. Null emission/CRC switches retain upstream settings; other nullable settings have the semantics documented on their properties. Input payloads are consumed synchronously; Complete must be called explicitly.

Structs

McapBatchReadResult

A successful batch result. Count identifies valid header/range entries and BytesWritten the valid payload prefix. On BufferTooSmall, RequiredLength is the entire pending message payload size; retry preserves that message. No result is published on exception.

McapCacheStatistics

Cumulative snapshot diagnostics: Hits counts cache reuse and ChunkLoads counts actual chunk loads, including loads not retained by the cache. Not allocation or memory statistics.

McapDataEnd

Data-section end marker containing its stored CRC.

McapFooter

Footer fields: summary offsets are byte positions from the MCAP origin (the initial Stream position for Stream inputs); SummaryCrc is the stored summary checksum.

McapIndexedReadEvent

An indexed protocol event. ReadChunk uses Length and Offset for compressed data excluding the Chunk header, relative to the MCAP origin. Message uses Length and Header.

McapLinearReadEvent

A linear protocol event. Length is in bytes; Opcode applies only to Record events.

McapMessageHeader

Message descriptor. LogTime and PublishTime are caller-defined nanoseconds; ChannelId refers to a declared channel.

McapMessageIndexEntry

Message log time in nanoseconds and byte offset within the uncompressed chunk record stream, not an offset from the MCAP origin.

McapMessageSeekRequest

One random message lookup. Index must remain undisposed during the call; Entry.Offset is relative to expanded chunk bytes.

McapPayloadRange

Byte offset and length within the payload storage passed to the same batch operation; not a file offset.

McapRecordFields

Allocation-free typed field cursor. Length-prefixed collections can be traversed with another cursor.

McapRecordReadResult

Caller-buffer read outcome. On Success, Opcode identifies the record and Length is the body bytes copied; on BufferTooSmall, Length is the required capacity and the same record remains pending. EOF does not prove full-file integrity.

McapRecordView

A record body validated at Parse time over caller-owned memory. Keep the underlying bytes unchanged for the entire lifetime of this view and all derived field cursors or spans. Read-only spans do not prevent mutation through other aliases. UTF-8 and collection fields remain borrowed spans; ToOwned creates an independent copy.

McapSeekRequest

A requested source position. Begin uses an unsigned absolute position; Current and End use a signed relative offset. Positions are relative to the MCAP origin.

McapSummaryOffset

Summary group descriptor with byte start from the MCAP origin (the initial Stream position for Stream inputs) and byte length.

McapSummaryReadEvent

A summary protocol event. Length applies to Read; Seek applies to Seek. Positions are relative to the MCAP origin. Other fields are not meaningful.

McapVisitResult

Number of completed visitor calls and why traversal stopped. VisitorStopped includes the message whose callback returned false; callback exceptions publish no result.

Interfaces

IMcapRecord

A record model. Results returned by Parse(byte, ReadOnlySpan<byte>) are independently owned. Pattern match the concrete record type to access its fields. Unknown opcodes return McapRawRecord; no payload or collection borrows the input span.
