Fizzy.McapSharp 文档

English · GitHub 仓库

在 .NET 8 / 10 应用中读写 MCAP 文件，保存带时间戳的消息、元数据和附件。支持 Windows x64 和 glibc Linux x64/ARM64，Linux 构建与验证基线为 Ubuntu 22.04。

入门

第一次使用？ 从写入和读取第一个文件开始：安装 NuGet 包，运行示例并查看结果。无需安装 Rust。
