Fizzy.McapSharp 文档

English · GitHub 仓库

Fizzy.McapSharp 为 .NET 8 提供 MCAP 文件读写。载荷编码和时钟基准由应用决定。按当前任务选择入口，无需先了解 Rust 或原生 ABI。

入门

首次接触项目，先看 README了解用途和支持平台；准备开始编码，阅读第一个文件，通过 NuGet 完成写入、读取、过滤和可选校验。
